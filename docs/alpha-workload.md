| **合计** | | | **15.0** | **100%** |

### 分工原则

- **按交付物分，不按代码文件分**：每项任务有唯一负责人，出问题找得到人。
- **交叉评审**：S1 的部署成果由测试角色验收，S7 的文档由部署角色对照代码核验，
  避免「自己写自己验」。
- **角色不固化**：文档角色在 S1 期间参与云端联调，测试角色在 S7 期间复核 README 中的命令。
