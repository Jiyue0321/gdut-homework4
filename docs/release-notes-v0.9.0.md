# v0.9.0 · Alpha 基线

**面面俱到 · 模拟面试多智能体**

> 粘贴一份简历和一份岗位 JD，让 HR、技术、压力三位 AI 面试官轮流发难。

**在线体验**：<https://interview-agent-test.streamlit.app>

免费实例无访问时休眠，冷启动约 30–60 秒，页面显示「Your app is waking up」属正常现象。

---

## 这个版本是什么

Alpha 冲刺的基线版本，对应作业第二阶段。

系统已经可以**完整跑通一次真实面试**：读简历与岗位 → 找出能力缺口 → 定向出题 →
逐题追问 → 交叉拷问 → 生成可导出的复盘报告。

**功能已冻结**，本次发布不含新需求。冲刺期只做稳定性修复与工程化补课
（已补：CI 接入、覆盖率基线、PDF 字体修复、两轮性能优化）。

## 功能

### 面试主流程

| 功能 | 说明 |
| --- | --- |
| 简历 × 岗位缺口雷达 | JD 要求、简历自评、面试实测三组能力画在同一张雷达图 |
| 文件导入 | 简历与 JD 支持上传 PDF / TXT / Markdown，自动抽取文字后可再编辑 |
| 三类面试官轮转 | HR / 技术 / 压力面试官，各有考察侧重与评分口径 |
| 行业定制题库 | 98 道参考题，覆盖后端、前端、AI、数据分析、测试、嵌入式、产品运营、金融科技等 9 个行业 |
| 自适应追问 | 回答含糊或缺量化依据时追问一次 |
| 交叉拷问 | 针对最弱一题，三位面试官轮流发难并独立打分，取中位数 |
| 复盘报告 | 加权总分、逐题证据、改进建议、话术模板，可导出 Markdown 或 PDF |

### 工程特性

| 特性 | 说明 |
| --- | --- |
| 确定性编排 | 阶段流转、题量上限、追问次数、评分聚合由代码控制，模型只负责生成内容 |
| 评分可复现 | 模型出维度分，加权 / 裁剪 / 中位数合并在 `mcp_server/rubric.py`，不交给模型自由发挥 |
| 工具层双实现 | `LocalTools`（进程内直调）与 `MCPTools`（stdio 子进程）同源，`USE_MCP` 一键切换 |
| 模型可切换 | DeepSeek / 通义千问 / 智谱 GLM，OpenAI 兼容协议，改环境变量即可，代码零改动 |
| 中文 PDF | 中文字体随仓库分发，导出的报告不依赖阅读器自带字体 |

## 本版本包含的修复

Alpha 冲刺期间修掉的问题，按影响排序：

- **重复出题**：同一简历亮点、同一能力被反复考察，追问体验雷同
- **PDF 导出失败**：MCP 路径下报告导出被误按 JSON 解析
- **大模型输出截断**：JSON 不合法或超长时解析崩溃，改为容错解析 + 回喂重试
- **文档编码**：抽取的文字带不可见字符，增强清洗与编码检测
- **意图误判**：作答中出现「测试」「报错」等词被当成系统反馈而拒收
- **复盘幻觉**：报告中重复出现同一段文本
- **长任务失败兜底**：模型超时后可重试，不必重开面试
- **示例数据不可用**：点「填入示例简历/JD」后无法开始面试

## 性能

单题耗时从基线 **5–9 秒降至 3.5 秒**（云端实测），做法是：

1. 原先每次提交回答调用两次模型，其中一半输出被丢弃 → **拆分打分与出题为并行调用**
2. **作答期间预取下一题**（出题不依赖本轮回答）

**尚未达到需求 N5 的「单题 ≤3 秒」。** 剩余瓶颈是「打分」这一次调用本身的模型响应时间
（1.6–3 秒），代码层已无压缩空间。如实记录，不调整目标值。
首轮分析 8 秒，满足 ≤20 秒的指标。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # 填入 API Key
streamlit run app.py
```

Windows 用户可直接双击 `start.bat`，脚本会自动建环境、装依赖、复制配置模板。
