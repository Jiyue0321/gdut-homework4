### 2.2 已完成的功能

简历 × 岗位缺口雷达、PDF/TXT/MD 导入、三类面试官轮转（HR / 技术 / 压力）、
单轮自适应追问、交叉拷问取中位数、98 题 / 9 行业定制题库、作答意图过滤、
大模型 JSON 容错与截断修复、Markdown + PDF 双格式导出、失败重试兜底。

### 2.3 关键设计决策（冲刺期不推翻）

1. **编排模式**：阶段流转、题量、追问次数、评分聚合由确定性代码控制，模型只负责生成内容。
2. **评分可复现**：模型出维度分，加权 / 裁剪 / 中位数合并在 `mcp_server/rubric.py`。
3. **工具层双实现**：`LocalTools` 与 `MCPTools` 同源，`USE_MCP` 一键切换——这是云端部署的降级保险。

## 4. 改进思路

三条原则，贯穿整个冲刺：

1. **先让人看到，再让人看懂。** 上线优先级高于一切新增功能，上线之后再谈架构。
   没有公网地址，后面所有工作的验收价值都要打折。
2. **把「靠自觉」换成「靠机器」。** 测试、覆盖率、部署状态全部交给 CI 和平台看板，
   不再依赖谁记得跑一下。
3. **冻结功能，偿还技术债。** 冲刺期业务代码只做稳定性修复，不接新需求；
   新想法记进 `docs/backlog.md`，留到 Beta。

## 8. 复盘制度

每周日做一次 15 分钟小复盘，只记「计划 vs 实际」的偏差与原因，累积到冲刺结束时并入本文档。
